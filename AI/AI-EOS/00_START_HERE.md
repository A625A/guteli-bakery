# AI Engineering Operating System (AI-EOS)

## Purpose
`AI/AI-EOS` is the canonical and permanent operating manual for this project. No competing AI-EOS directory may be created.

## Workflow
1. Read numbered documents `00` through `19` in order.
2. Read `CAPABILITY_TABLE.md` and `CURRENT_TASK.md`.
3. Treat `AI-EOS_Bootstrap_Prompt.md` as the adoption and approval policy.
4. Summarize understanding.
5. Produce a plan.
6. Wait for approval before major implementation or a new milestone.

## Documentation boundary

Long-term project memory is maintained in the external Obsidian folder `Phase 2 - Guteli Demo`. The application must build and run without that vault. Repository documentation must use project-relative paths.

The only document intended to change frequently is `CURRENT_TASK.md`. The decision log is append-only.
