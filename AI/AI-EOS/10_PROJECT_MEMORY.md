# Project Memory

The canonical long-term project memory is the external Obsidian folder `Phase 2 - Guteli Demo`.

Maintain:

- Guteli Demo Home
- Project Context
- Phase 1 Findings Applied
- Requirements and Scope Boundaries
- Customer Journeys
- Design System and UX Decisions
- Architecture and Future Integrations
- Decisions and Current State
- Roadmap and Scenario Guide
- Learnings and Open Questions
- Session Log
- Testing and Deployment

The repository remains self-contained when the vault is absent. `CURRENT_TASK.md` provides the active in-repository state required for an engineering session.
