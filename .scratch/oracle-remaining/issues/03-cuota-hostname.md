# 03: Confirmar recursos gratuitos y hostname

**Estado vigente 25/10/2026:** Cuenta independiente del amigo sin confirmar; usuario autorizado, región, cuota, costos, capacidad y hostname pendientes. Ver [checkpoint](../../../docs/operations/oracle/CHECKPOINT.md). Las restricciones Git y bloqueos npm de los apartados inferiores son históricos; prevalece la autorización de consolidación actual. Ningún criterio externo se marca completado.

**What to build / Qué entrega:** El propietario puede decidir si cabe una VM independiente gratuita y cuál hostname usar, con evidencia no sensible.

**Blocked by / Bloqueado por:** Autorización para inspección manual de cuenta por el propietario; ninguna dependencia técnica local.

**Status / Estado:** PENDIENTE DE AUTORIZACIÓN EXTERNA.

**Criterios de aceptación:**

- [ ] Registrar tenancy/tipo de cuenta/región principal y uso de todos los compartments, identificando hackathon sin modificarlo.
- [ ] Comprobar saldo A1, boot/block, backups, IP y costos recurrentes frente a propuesta; no contar créditos ni prometer capacidad física.
- [ ] Comprobar registrabilidad del subdominio gratuito con el proveedor, sin registrarlo ni modificar DNS durante la inspección.
- [ ] Emitir go/no-go Q0 condicionado y aprobaciones requeridas; si no cabe, documentar espera/opciones gratuitas sin compartir o reducir otro servidor.

**Límites:** Sin acceso externo privilegiado, datos reales, gasto, commit/push/merge/deploy ni cambios a otros proyectos sin autorización específica. No repetir evidencia válida; registrar qué cambio justifica cada prueba nueva.
